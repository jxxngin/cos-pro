# 학습지 구성

## 1. 목적

- 대상: COS Pro 3급(Python) 응시자. 수록 문제는 **이미 한 번씩 풀어 본 문제**다.
- 용도: **시험 전날 복습**. 시간이 지나 잊어버린 풀이를 다시 떠올리게 한다.
- 핵심: 문제를 다시 실어 주는 문제집이 아니다. 한 문제를 **어떤 방법으로 풀 수 있는지**
  (예: 평균을 `sum()`으로 구할지, 반복문으로 더할지)를 비교하고, **직접 써 보게** 한다.
- 보는 방식: **A4로 인쇄해서 펜으로 푼다.** 화면으로 보는 것은 부수적이다.

## 2. 학습지 전체 구성

| 순서 | 구성 | 내용 |
| --- | --- | --- |
| 1 | 표지 | 제목, 범위(3급), 목차 |
| 2 | 한 장 요약 (치트시트) | 수록 문제에 실제로 나온 문법만 모은 1~2쪽 요약 |
| 3 | 패턴별 장(Chapter) | 같은 풀이 패턴의 문제끼리 묶은 문제 페이지 |
| 4 | 장 끝 정답 | 각 장 마지막에 그 장의 "직접 써 보기" 정답 |

- 문제는 **풀이 패턴별로 묶는다.** 원래 번호는 `1세트-03`처럼 문제마다 표시한다.
- 패턴 분류(장 구성) 초안은 [problems.md](problems.md)에 있다.
- "직접 써 보기" 정답은 **각 장 끝**에 둔다. 학습지 맨 뒤에 모으면 장을 오가야 해서
  복습 흐름이 끊기기 때문이다.

### 한 장 요약에 들어갈 항목 (초안)

- 입력 처리: `input()`, `int(input())`, `input().split()`, `list(map(int, input().split()))`
- 출력 형식: `print`의 `sep` / `end`, 소수점 자리 출력(f-string, `%` 포맷, `round`의 차이)
- 연산자: `/` vs `//`, `%`, 비교 연산자(문자열 비교 포함)
- 내장 함수: `sum`, `max`, `min`, `abs`, `len`, `range`
- 리스트·문자열: 인덱스(0부터 시작), 슬라이싱 `[start:stop:step]`, `index`, `count`
- 문자열 메서드: `lower`, `upper`, `islower`, `isupper`
- 반복문 · 조건문 기본 형태

수록 문제에 나오지 않는 문법은 넣지 않는다. 범위를 넓히지 않고, 시험 전날 볼 분량을 유지하기 위해서다.

## 3. 문제 페이지 구성

문제 하나는 아래 순서로 구성한다.

| # | 구역 | 내용 |
| --- | --- | --- |
| 1 | 머리말 | 원래 번호(`1세트-03`), 유형 배지(빈칸 채우기 / 함수 작성), 주제 태그 |
| 2 | 문제 요약 | 원문을 2~3줄로 줄인 설명 + 대표 입출력 예시 1개 |
| 3 | 핵심 아이디어 | 한 줄. 예: "세 점수를 더해 3으로 나누고, 소수 둘째 자리까지 출력" |
| 4 | 풀이 방법 비교 | 방법 A / 방법 B 코드와 한 줄 메모. 시험 코드가 쓰는 방식에 표시 |
| 5 | 헷갈리기 쉬운 점 | 실수하기 쉬운 부분 1~3개 |
| 6 | 직접 써 보기 | 핵심 부분을 빈칸으로 만든 코드 + 손으로 쓸 줄 공간 |

### 분량 기준

- **기본: 문제 1개 = A4 1쪽**
- **쉬운 문제: 문제 2개 = A4 1쪽** (각 문제를 반 쪽으로 줄인다)
  - 쉬운 문제 기준: 정답 코드가 3줄 안팎이고, 비교할 풀이 방법이 두 개를 넘지 않는 문제
  - 반 쪽 문제는 "헷갈리기 쉬운 점"을 1개로 줄이고, 쓰기 줄도 줄인다.
  - 같은 장 안의 쉬운 문제끼리 짝을 짓는다.
- 어떤 문제가 쉬운 문제인지는 [problems.md](problems.md)의 분량 열에 적는다.

## 4. 폴더 구조

2급이 추가될 수 있으므로 급수별로 폴더를 나눈다.

```
cos-pro/
├─ docs/                  규칙 문서 (이 폴더)
├─ assets/
│  └─ css/
│     ├─ base.css         공통 스타일 (색상, 글꼴, 구성 요소)
│     └─ print.css        인쇄 전용 스타일 (A4, 쪽 나눔)
├─ grade3/
│  ├─ index.html          표지 + 목차
│  ├─ cheatsheet.html     한 장 요약
│  ├─ ch01-xxx.html       장별 문제 페이지 (+ 장 끝 정답)
│  └─ ...
└─ grade2/                (추후)
```

- 파일 이름은 영문 소문자와 하이픈만 쓴다. 장 파일은 `chNN-주제` 형식이다. 예: `ch03-sum-max.html`
- HTML은 장마다 따로 만든다. 장별로 PR을 올리고, 장별로 다시 인쇄하기 쉽게 하기 위해서다.
- PDF는 사용자가 요청할 때만 만든다. 만들게 되면 HTML 파일을 순서대로 합친다.
