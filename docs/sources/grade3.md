# 3급 원문 자료

사용자가 준 문제 텍스트와 시험 화면 스크린샷을 옮겨 적은 자료다. 학습지를 만들 때 이 문서를 원본으로 쓴다.

- 레이아웃은 무시하고 내용만 옮겼다. `Copy` 글자와 중복된 입력·출력 블록은 뺐다.
- 원문 오류는 여기서는 **고치지 않고 그대로 둔다**(⚠ 표시). 고친 내용은 학습지에 반영한다. → [problems.md](../problems.md) 3절
- 코드 틀의 `⬜`는 시험 화면의 빈칸이다. 줄 구성과 공백은 화면 그대로다.

## 시험 코드 형식 요약

| 구분 | 형식 |
| --- | --- |
| 1세트 빈칸 채우기 | 감싸는 코드 없이 바로 시작. 출력은 `print("%d" % 값)`처럼 `%` 포맷 |
| 2세트 빈칸 채우기 | `if __name__ == "__main__":` 안에 코드 |
| 함수작성 (두 세트 공통) | 빈 편집기. 주석 예시만 있음: `# a = input()` / `# print(a)` |

## 1세트

### 1세트-01 · 함수작성
k에 3씩 더하여 크기가 작은 순서대로 n개 출력한다.
- 입력: 두 자연수 k, n (2 ≤ k ≤ 100, 1 ≤ n ≤ 100), 한 줄에 하나씩
- 출력: k부터 3씩 더한 수 n개를 공백으로 구분해 출력
- 예제: `7`, `5` → `7 10 13 16 19` / `3`, `4` → `3 6 9 12`

### 1세트-02 · 함수작성
숫자 리스트 n에서 7보다 앞에 있는 숫자의 개수를 출력한다.
- 입력: 숫자 리스트 n (원소 1~100 자연수, 크기 1~10,000, 7은 한 번만 있음), 한 줄에 공백 구분
- 예제: `14 45 50 3 7 11 5 23 9 80` → `4` (7 앞: 14, 45, 50, 3)

### 1세트-03 · 함수작성
두 수 중 더 작은 수를 출력한다.
- 입력: 정수 두 개 (-1,000 ~ 1,000, 서로 다름), 한 줄에 하나씩
- 예제: `27`, `64` → `27`

### 1세트-05 · 함수작성
자연수 n을 받아, 별(*)은 n부터 1까지 1씩 줄고 하이픈(-)은 0부터 n-1까지 1씩 늘면서 교차해 출력한다.
- 입력: 자연수 n (2~100)
- 기준(n=5): 하이픈 0·1·2·3·4개, 별 5·4·3·2·1개 → 별 5개, 하이픈 1개, 별 4개, … 순서
- 예제: `5` → `*****-****--***---**----*` / `3` → `***-**--*`
