# 문제 목록과 패턴 분류

받은 문제 20개(1세트 10개, 2세트 10개)의 목록이다. 장 구성은 **초안**이며,
장별 학습지 PR에서 실제로 써 보면서 조정할 수 있다. 조정하면 이 문서도 함께 고친다.

## 1. 문제 목록

- 빈칸 문제의 정답 코드 칸이 한 줄짜리 빈칸만 있는 경우가 많다. 예) `1세트-04`는 `⬜` 한 줄, `1세트-08`은 `print(⬜)`.
  이런 문제는 시험 빈칸 외에 "직접 써 보기"에서 다른 줄도 빈칸으로 만든다.
- 시험 코드 틀에서 `sum`, `str`을 변수 이름으로 쓴다(`1세트-04`, `1세트-06`, `1세트-09`). 이렇게 하면 같은 코드 안에서
  내장 함수 `sum()`, `str()`을 쓸 수 없다. 풀이 방법 비교에서 내장 함수를 쓰는 방법 A를 보여 줄 때는 이 점을 "헷갈리기 쉬운 점"에 적는다.

## 2. 패턴별 장 구성 (초안)

| 장 | 제목 | 다루는 패턴 | 문제 |
| --- | --- | --- | --- |
| 1 | 기본 연산과 출력 형식 | 사칙연산, `abs`, 문자열 연결, 소수점 자리 출력 | 1세트-10, 1세트-07, 2세트-03 |
| 2 | 비교와 조건 | `if`/`elif`/`else`, `min`·`max`·`abs` 비교, `%`로 배수 판별, 순서 비교 | 1세트-03, 2세트-02, 2세트-04, 2세트-10, 2세트-05 |
| 3 | 합계 · 평균 · 최댓값 | `sum` vs 반복문 누적, `max` vs 반복문 비교, 문자열 대소 비교 | 2세트-01, 2세트-08, 1세트-08 |
| 4 | 개수 세기 | `count` vs 반복문 + 조건, `index` vs 반복문 + `break` | 1세트-06, 2세트-06, 2세트-09, 1세트-02 |
