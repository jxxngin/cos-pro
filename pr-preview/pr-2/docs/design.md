# 디자인

## 1. 방향

- **깔끔한 스타일**에 **적당한 색**을 쓴다. 흑백만으로 만들지 않는다.
- 인쇄가 기준이다. 넓은 면적은 **옅은 색**으로 채우고, 진한 색은 글자·선·배지처럼 작은 곳에만 쓴다.
- 장식보다 **읽기 쉬움**이 먼저다. 한 쪽 안에서 눈이 위에서 아래로 자연스럽게 내려가야 한다.

## 2. 색상

CSS 변수로 정의하고, 모든 페이지가 같은 변수를 쓴다. 아래 값은 초안이며 템플릿 PR에서 실제 인쇄 결과를 보고 조정한다.

| 용도 | 변수 | 값(초안) | 쓰는 곳 |
| --- | --- | --- | --- |
| 메인 | `--c-primary` | `#4338CA` (인디고) | 장 제목, 문제 번호, 구분선 |
| 메인 옅은 색 | `--c-primary-soft` | `#EEF2FF` | 장 머리띠, 핵심 아이디어 상자 |
| 빈칸 채우기 | `--c-blank` | `#D97706` (주황) | 유형 배지, 빈칸 번호 |
| 빈칸 옅은 색 | `--c-blank-soft` | `#FEF3C7` | 빈칸 상자 바탕 |
| 함수 작성 | `--c-write` | `#059669` (초록) | 유형 배지 |
| 함수 작성 옅은 색 | `--c-write-soft` | `#D1FAE5` | 배지 바탕 |
| 주의 | `--c-warn` | `#DC2626` (빨강) | "헷갈리기 쉬운 점" 머리글 |
| 주의 옅은 색 | `--c-warn-soft` | `#FEF2F2` | "헷갈리기 쉬운 점" 상자 |
| 본문 글자 | `--c-text` | `#1F2937` | 본문 |
| 보조 글자 | `--c-muted` | `#6B7280` | 출처 번호, 메모 |
| 선 | `--c-line` | `#E5E7EB` | 표·상자 테두리, 쓰기 줄 |
| 코드 바탕 | `--c-code-bg` | `#F8FAFC` | 코드 블록 |

- 시험 화면은 어두운 편집기지만, 학습지 코드 블록은 **밝은 바탕**으로 한다. 인쇄 잉크를 아끼고 위에 필기하기 쉽게 하기 위해서다.
- 코드 문법 색은 키워드·문자열·숫자·주석 4가지만 구분하고, 진하지 않은 색을 쓴다.

## 3. 글꼴

| 용도 | 글꼴 | 대체 글꼴 |
| --- | --- | --- |
| 본문 | Pretendard | `Malgun Gothic`, sans-serif |
| 코드 | D2Coding | `Consolas`, monospace |

- 본문 10.5pt, 코드 10pt, 문제 제목 13pt, 장 제목 18pt를 기준으로 한다.
- 코드는 줄 번호를 붙인다. 해설에서 "3번 줄"처럼 가리키기 위해서다.

## 4. 구성 요소

| 구성 요소 | 모양 |
| --- | --- |
| 장 머리띠 | 장 첫 쪽 맨 위. 메인 옅은 색 바탕에 장 번호와 장 제목, 이 장에서 다루는 패턴 한 줄 |
| 문제 머리말 | 원래 번호(보조 글자색) + 유형 배지 + 주제 태그(테두리만 있는 작은 알약 모양) |
| 유형 배지 | `빈칸 채우기`는 주황, `함수 작성`은 초록. 옅은 바탕에 진한 글자 |
| 입출력 예시 | 두 칸짜리 작은 표 (입력 / 출력). 고정폭 글꼴 |
| 핵심 아이디어 | 메인 옅은 색 상자, 왼쪽에 메인 색 굵은 선 |
| 풀이 방법 비교 | 방법 A / 방법 B를 나란히 놓은 두 칸 구성(폭이 모자라면 위아래). 각 칸 아래에 한 줄 메모. 시험 코드와 같은 방식에는 `시험 코드 방식` 표시 |
| 빈칸 | 주황 옅은 바탕 상자 안에 ①②③ 번호. 손으로 쓸 수 있도록 충분히 넓게 |
| 헷갈리기 쉬운 점 | 빨강 옅은 바탕 상자, 머리글 "헷갈리기 쉬운 점" |
| 쓰기 줄 | 옅은 회색 가로줄. 줄 간격 8mm |
| 원문 수정 표시 | 고친 문장 옆에 작은 보조 글자로 `원문 수정` (본문을 방해하지 않게) |

## 5. 인쇄 규칙

- 용지: **A4 세로**, 여백은 위아래 14mm, 좌우 16mm를 기준으로 한다.
- **한 문제가 두 쪽에 걸치지 않게 한다.** (`break-inside: avoid`)
- 장은 **새 쪽에서 시작**하고, 장 끝 정답도 새 쪽에서 시작한다.
- 쪽 아래에 `COS Pro 3급 · 장 제목 · 쪽 번호`를 넣는다.
- 배경색이 인쇄되도록 `print-color-adjust: exact`를 쓴다.
- 화면에서 볼 때는 A4 크기 종이 모양으로 보여 주고, 인쇄 결과와 최대한 같게 맞춘다.
