# 학습지 구성

## 1. 목적

- 대상: COS Pro 3급(Python) 응시자. **초등학생부터 고등학생까지** 쓸 수 있어야 한다. 수록 문제는 **이미 한 번씩 풀어 본 문제**다.
- 용도: **시험 전날 복습**. 시간이 지나 잊어버린 풀이를 다시 떠올리게 한다.
- 핵심: 한 문제를 **작은 미션으로 쪼개서 하나씩 해결**하게 한다. 입력 받기 → 숫자로 바꾸기 → 핵심 개념 → 계산·조건 → 완성 코드 순서로, 막히는 곳 없이 한 단계씩 나아간다.
- 풀이 방법이 여러 가지면(예: 평균을 `sum()`으로 구할지, 반복문으로 더할지) **문제를 A / B로 나눠** 각각 미션으로 푼다.
- 보는 방식: **A4로 인쇄해서 펜으로 푼다.** 화면으로 보는 것은 부수적이다.

## 2. 학습지 전체 구성

| 순서 | 구성 | 내용 |
| --- | --- | --- |
| 1 | 표지 | 제목, 범위(3급), 목차 |
| 2 | 한 장 요약 (치트시트) | 수록 문제에 실제로 나온 문법만 모은 1~2쪽 요약 |
| 3 | 패턴별 장(Chapter) | 같은 풀이 패턴의 문제끼리 묶은 문제 페이지 |
| 4 | 장 끝 정답 | 각 장 마지막에 그 장의 모든 미션 정답 |

- 문제는 **풀이 패턴별로 묶는다.** 원래 번호는 `1세트-03`처럼 문제마다 표시한다.
- 패턴 분류(장 구성) 초안은 [problems.md](problems.md)에 있다.
- 미션 정답은 **각 장 끝**에 모은다. 학습지 맨 뒤에 모으면 장을 오가야 해서
  복습 흐름이 끊기기 때문이다.

### 한 장 요약에 들어갈 항목 (초안)

- 입력 처리: `input()`, `int(input())`, `input().split()`, `list(map(int, input().split()))`
- 출력 형식: `%` 포맷(`"%d"`, `"%s"`, `"%.1f"`, 여러 값은 `"%d %d" % (a, b)`) — 시험 틀이 주로 쓰는 방식,
  `print`의 `sep` / `end`, 소수점 자리 출력에서 `round`·f-string과의 차이
- 연산자: `/` vs `//`, `%`, 비교 연산자(문자열 비교 포함)
- 내장 함수: `sum`, `max`, `min`, `abs`, `len`, `range`
- 리스트·문자열: 인덱스(0부터 시작), 슬라이싱 `[start:stop:step]`, `index`, `count`
- 문자열 메서드: `lower`, `upper`, `islower`, `isupper`
- 반복문 · 조건문 기본 형태

수록 문제에 나오지 않는 문법은 넣지 않는다. 범위를 넓히지 않고, 시험 전날 볼 분량을 유지하기 위해서다.

## 3. 문제 페이지 구성 (미션식)

문제 하나는 아래 순서로 구성한다. 견본: [grade3/sample.html](../grade3/sample.html)

| # | 구역 | 내용 |
| --- | --- | --- |
| 1 | 머리말 | 제목, 원래 번호(`1세트-03`), 유형 배지(빈칸 채우기 / 함수 작성), 주제 태그. A / B로 나눈 문제는 제목 뒤에 `· A`, `· B` |
| 2 | 문제 읽기 | 쉬운 말로 줄인 문제(2~3줄) + 입출력 예시 |
| 3 | 목표 | 이 문제에서 할 일 한 줄 |
| 4 | 미션 1 ~ n | 작은 단계 하나씩. 각 미션은 **알아 두기 → (주의) → 질문 → 쓰기 칸** |
| 5 | 최종 미션 | 함수 작성: 완성 코드를 처음부터 다시 쓰기 / 빈칸 채우기: 완성 코드 쓰기 + 시험 코드 틀의 빈칸 채우기 |

### 미션 순서 (기본)

1. **입력 받기** — `input()`으로 받아 변수에 넣기
2. **리스트로 나누기** — 한 줄에 여러 값이 오면 `split()` (필요할 때만)
3. **숫자로 바꾸기** — `input()`은 문자열이므로 `int()`, `list(map(int, ...))` (숫자일 때만)
4. **핵심 개념** — 인덱스, 내장 함수, 반복 등 이 문제에서 새로 필요한 것. 막히기 쉬운 개념은 **칸 그림**으로 먼저 보여 준다
5. **계산 · 조건 · 출력**
6. **최종 미션**

### 반복되는 미션

- "입력 받기", "숫자로 바꾸기"처럼 거의 모든 문제에 나오는 미션은 **장의 첫 문제에서만 자세히** 설명한다.
- 같은 장의 두 번째 문제부터는 **한 줄짜리 알아 두기 + 미션**만 둔다. 예) "A의 미션 1~2와 같아요. `int(input())`"
- 그 장에서 **처음 나오는 개념**(예: 2세트-10의 `split`, `map`, 인덱스)은 몇 번째 문제든 자세히 설명한다.

### 분량 기준

- 문제 하나는 미션 수에 따라 **1~3쪽**이다. 분량이 늘어나는 것은 감수한다.
- **미션 하나는 두 쪽에 걸치지 않는다.** 쪽이 모자라면 미션을 통째로 다음 쪽으로 넘기고, 이어지는 쪽 머리말에 `(이어서)`를 붙인다.
- 앞 문제가 쪽 중간에서 끝나면 다음 문제를 같은 쪽에서 이어서 시작해도 된다.
- 최종 미션처럼 길게 쓰는 칸은 남는 공간을 모두 쓰기 줄로 채운다.

## 4. 폴더 구조

2급이 추가될 수 있으므로 급수별로 폴더를 나눈다.

```
cos-pro/
├─ docs/                  규칙 문서 (이 폴더)
├─ assets/
│  └─ css/
│     ├─ base.css         공통 스타일 (색상, 글꼴, 구성 요소)
│     └─ print.css        인쇄 전용 스타일 (A4, 쪽 나눔)
├─ grade3/
│  ├─ index.html          표지 + 목차
│  ├─ cheatsheet.html     한 장 요약
│  ├─ ch01-xxx.html       장별 문제 페이지 (+ 장 끝 정답)
│  └─ ...
└─ grade2/                (추후)
```

- 파일 이름은 영문 소문자와 하이픈만 쓴다. 장 파일은 `chNN-주제` 형식이다. 예: `ch03-sum-max.html`
- HTML은 장마다 따로 만든다. 장별로 PR을 올리고, 장별로 다시 인쇄하기 쉽게 하기 위해서다.
- PDF는 사용자가 요청할 때만 만든다. 만들게 되면 HTML 파일을 순서대로 합친다.
