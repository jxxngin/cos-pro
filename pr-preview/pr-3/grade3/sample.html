J · Q · K 카드 게임

2세트-05 빈칸 채우기 문자열 인덱스index()
문제 설명

A와 B는 카드게임을 하고 있습니다.

J, Q, K로 구성된 3장의 카드에서 A와 B가 1장씩 뽑았을 때, 우선순위가 높은 카드를 뽑은 사람이 이기게 됩니다. 카드의 우선순위는 J < Q < K 입니다.

A와 B가 뽑은 카드가 순서대로 저장된 문자열 cards가 주어졌을 때, 게임에서 이기는 사람을 출력하는 프로그램의 빈칸을 채우십시오.

입력 설명

cards : A가 뽑은 카드와 B가 뽑은 카드가 순서대로 저장된 문자열
각 문자는 J, Q, K 중 하나의 값을 가지며 중복된 원소는 존재하지 않음

출력 설명

A가 뽑은 카드의 우선순위가 높으면 A를 출력하고, B가 뽑은 카드의 우선순위가 높으면 B를 출력합니다.

예제
예제cardsresult
#1QKB
#2KJA

예제 #1. A가 Q를 뽑고, B가 K를 뽑은 상황
K가 Q보다 우선순위가 높으므로 K를 뽑은 B 승리
출력값 : B
예제 #2. A가 K를 뽑고, B가 J를 뽑은 상황
K가 J보다 우선순위가 높으므로 K를 뽑은 A 승리
출력값 : A

입력
QK
출력
B

단계별로 풀기

1.입력을 cards에 대입한다.힌트

2.A의 카드를 a에, B의 카드를 b에 대입한다.힌트

3.우선순위가 낮은 카드부터 쓴 문자열 "JQK"를 priority에 대입한다.

4.priority에서 a, b의 인덱스를 구해 rank_a, rank_b에 대입한다.힌트

2장 힌트

1세트-03 · 두 수 중 작은 수 · A

  1. 1

    input()은 입력 한 줄을 받아 문자열로 돌려준다. 받은 값은 변수에 대입해야 다시 쓸 수 있다.

    name = input()
  2. 2

    input()으로 받은 값은 숫자처럼 보여도 문자열이다. 크기를 비교하거나 계산하려면 int()로 정수로 바꾼다. 바꾸지 않으면 문자열끼리 비교하므로 "100" < "27"이 True가 된다.

    age = int(age)        # 이미 받은 값을 바꾼다
age = int(input())    # 받으면서 바로 바꾼다
  3. 3

    min(a, b)는 둘 중 작은 값을, max(a, b)는 큰 값을 돌려준다. 예) min(3, 8) → 3, max(3, 8) → 8

    if 조건: 아래 줄은 조건이 참일 때, else: 아래 줄은 거짓일 때 실행된다. 아래 줄은 4칸 들여 쓴다.

2세트-10 · n번째 원소의 부호

  1. 2

    split()은 문자열을 공백 기준으로 잘라 리스트로 만든다. 잘린 조각은 아직 문자열이다.

    "1 2 3".split()    # ['1', '2', '3']
  2. 3

    list(map(int, 리스트))는 리스트의 모든 원소에 int()를 적용한 새 리스트를 만든다.

    list(map(int, ['1', '2', '3']))    # [1, 2, 3]
  3. 5

    리스트의 인덱스는 0부터 시작한다. 따라서 n번째 원소의 인덱스는 n - 1이다. arr[n]은 n+1번째 원소다.

    번째12345
    arr-85999111-320
    인덱스01234
  4. 6

    경우가 셋이면 if / elif / else를 쓴다. 위에서부터 차례로 검사해 처음 참인 곳 하나만 실행한다. 같은지 비교할 때는 ==를 쓴다.

    if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")

2세트-05 · J · Q · K 카드 게임

  1. 1

    카드는 문자이므로 int()로 바꾸지 않는다.

  2. 2

    문자열도 리스트처럼 인덱스로 한 글자씩 꺼낼 수 있다. 첫 글자의 인덱스는 0이다.

    cardsQK
    인덱스01
    카드 주인AB
  3. 4

    문자열.index(글자)는 그 글자의 인덱스를 돌려준다. "JQK"는 우선순위가 낮은 카드부터 썼으므로 인덱스가 클수록 우선순위가 높다.

    priorityJQK
    인덱스012
    "JQK".index("Q")    # 1
  4. 5

    인덱스가 큰 쪽이 이긴다. rank_a가 더 작으면 B가 이긴다.

  5. 7

    시험 코드는 index() 대신 반복문으로 위치를 찾는다.

    1. winner를 'A'로 정해 두고, B가 이기는 경우만 찾는다.
    2. 바깥 for: priority에서 A의 카드가 있는 인덱스 i를 찾는다.
    3. 안쪽 for: i 바로 다음 칸부터 끝까지 보면서 B의 카드가 있으면 B가 이긴다.
