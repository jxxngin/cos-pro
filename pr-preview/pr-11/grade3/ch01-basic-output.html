유형1 문제 10 함수 작성
문제 설명

두 수의 차이 값의 절댓값을 구하려 합니다.

숫자 두 개를 전달받아, 두 수의 차이 값의 절댓값을 출력해주세요.

입력 설명

숫자 두 개가 주어집니다.

  • 수는 -1,000 이상 1,000 이하인 정수입니다.
출력 설명

전달받은 두 수의 차이 값을 구하고 그 결괏값에 절댓값을 출력해주세요.

예제
n1n2result
253
입력
2
5
출력
3
예제 설명

2와 5의 차이 값은 –3이고 그 결과에 절댓값은 3이므로 3을 출력합니다.

내장 함수 abs()는 숫자의 부호를 뗀 값(절댓값)을 돌려준다.

유형2 문제 3 빈칸 채우기
문제 설명

밑변과 높이가 저장된 정수 변수 base, height가 주어졌을 때, 삼각형 넓이와 사각형 넓이를 출력하는 프로그램의 빈칸을 채우십시오.

입력 설명

base : 도형의 밑변 길이로서 1이상 999 이하의 자연수
height : 도형의 높이 길이로서 1이상 999 이하의 자연수

출력 설명

삼각형 넓이와 사각형 넓이를 차례대로 출력합니다.

삼각형 넓이 : 실수 출력(단, 소수점 첫번째 자리까지 출력)
사각형 넓이 : 정수 출력

예제
baseheightresult
11316.5 33
입력
11
3
출력
16.5 33
예제 설명

밑변 : 11, 높이 : 3
삼각형 넓이 : 11 x 3 / 2 = 16.5
사각형 넓이 : 11 x 3 = 33
출력값 : 삼각형 넓이와 사각형 넓이를 순서대로 출력합니다.

나눗셈 /의 결과는 실수다. % 포맷은 문자열 속 자리 표시에 값을 넣어, 정수인지 실수인지와 소수점 자릿수를 정해 출력한다.

1장 힌트

유형1 문제 10 · 두 수의 차의 절댓값 · A

  1. 1

    input()은 입력 한 줄을 문자열로 돌려준다. 숫자로 계산하려면 int()로 정수로 바꾼다. 입력이 두 줄이면 input()을 두 번 쓴다.

    age = int(input())
  2. 3

    abs(x)는 x의 부호를 뗀 값을 돌려준다. 예) abs(-7) → 7, abs(7) → 7

유형1 문제 10 · 두 수의 차의 절댓값 · B

  1. 3

    음수에 -1을 곱하면 부호가 바뀌어 양수가 된다. 0과 양수는 그대로 두면 이미 절댓값이다.

    x = -4
if x < 0:
    x = x * -1
print(x)    # 4

유형2 문제 3 · 삼각형 · 사각형 넓이

  1. 2

    /로 나눈 결과는 항상 실수다. 나누어떨어져도 .0이 붙는다. 예) 7 * 4 / 2 → 14.0

  2. 4

    "형식" % 값은 값을 형식에 맞춘 문자열을 만든다. %.2f는 소수점 둘째 자리까지, %d는 정수다. 값이 여러 개이면 괄호로 묶어 순서대로 넣는다. 예) "%.2f" % 3.14159 → 3.14, "%d-%d" % (3, 4) → 3-4

  3. 6

    시험 코드는 빈칸 ③에 형식 문자열을 넣고, % 뒤의 (triangle, rectangle)가 그 형식에 차례로 들어간다. ①·②는 2·3단계에서 쓴 식이다.
