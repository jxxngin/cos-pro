한 장 요약

수록 문제에 실제로 나온 문법만 모았다. 예시 값은 문제와 다르다.

1입력 받기

input()은 입력 한 줄을 문자열로 돌려준다. 입력이 여러 줄이면 그 줄 수만큼 부른다.

한 줄에 값 하나 · 입력 두 줄: 27, 5 
s = input()          # 첫째 줄 → "27"
n = int(input())     # 둘째 줄 → 5
한 줄에 값 여러 개 · 입력 두 줄: 3 8 1, 4 0 6 
a = input().split()
# 첫째 줄 → ['3', '8', '1']
b = list(map(int, input().split()))
# 둘째 줄 → [4, 0, 6]

정수로 바꾸지 않으면 더하기가 이어 붙이기가 된다. 예) "27" + "1" → "271", int("27") + 1 → 28

2출력 형식

% 포맷: 형식 % 값 
print("%d" % 7)           # 7
print("%s!" % "hi")       # hi!
print("%.2f" % 2.5)       # 2.50
print("%d %d" % (3, 4))   # 3 4
print의 end 
print("a", end=" ")
print("b")     # a b
print("x", end="")
print("y")     # xy
print(1, 2)    # 1 2 (값 사이 공백)
  • %d 정수, %s 문자열, %.1f %.2f 소수점 첫째·둘째 자리까지 실수. 값이 여러 개이면 괄호로 묶어 순서대로 넣는다.
  • end를 쓰지 않으면 출력 뒤에 줄이 바뀐다. end=" "는 공백, end=""는 아무것도 붙이지 않는다.
  • round(2.50, 2)는 2.5가 된다(끝자리 0이 사라짐). 자릿수를 꼭 맞춰야 하면 "%.2f"를 쓴다.

3산술 연산

9 / 3       # 3.0 (항상 실수)
7 % 2       # 1 (나머지)
12 % 4 == 0 # True (나누어떨어짐)
abs(-7)     # 7 (절댓값)
"ab" * 3    # "ababab"

짝수·홀수, 배수는 % 나머지로 판단한다.

4비교 · 논리

3 < 5              # True
7 == 7             # True
7 != 7             # False
"cat" < "dog"      # True
"a" <= "q" <= "z"  # True

문자열은 사전 순서로 비교한다. 조건 여러 개는 and(모두 참), or(하나라도 참)로 잇는다.

5내장 함수

리스트 · 값 
sum([1, 2, 3])      # 6
max([3, 9, 4])      # 9
min(3, 8)           # 3
len("Hello")        # 5
len([3, 9, 4])      # 3

list(range(4))        # [0, 1, 2, 3]
list(range(2, 5))     # [2, 3, 4]
list(range(1, 9, 3))  # [1, 4, 7]

6인덱스와 슬라이싱

nums = [10, 20, 30, 40, 50]
값1020304050
인덱스01234
값 꺼내기 
nums[0]       # 10 (첫 번째)
nums[4]       # 50 (마지막: len - 1)
nums[1:3]     # [20, 30] (끝 미포함)
nums[1::2]    # [20, 40] (2칸씩)
"Hello"[:3]   # "Hel"
  • 인덱스는 0부터 시작한다. 길이가 5이면 마지막 인덱스는 4다. 없는 인덱스를 쓰면 오류(IndexError)가 난다.
  • 슬라이싱 [시작:끝:간격]은 끝 위치를 포함하지 않는다. 간격이 양수(생략하면 1)일 때 시작을 비워 두면 처음부터, 끝을 비워 두면 마지막까지라는 뜻이다. 문자열에도 똑같이 쓴다.

7문자열 · 리스트 메서드

[7, 3, 9].index(9)   # 2 (위치)
"banana".count("a")  # 3 (개수)
"HeLLo".lower()      # "hello"
"HeLLo".upper()      # "HELLO"
"b".islower()        # True
"B".islower()        # False

lower()·upper()는 바뀐 새 문자열을 돌려준다. 원래 변수는 그대로다.

8조건문

score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")     # 출력: B
else:
    print("C")

위에서부터 처음 참인 칸 하나만 실행한다. 비교는 ==, 대입은 =.

9반복문

값을 하나씩 
for ch in "abc":
    print(ch, end="")
# abc
위치(인덱스)로 
word = "abc"
for i in range(len(word)):
    print(i, word[i])
# 0 a
# 1 b
# 2 c
반복 안의 반복 · 멈추기 
for i in range(1, 3):
    for j in range(1, 3):
        print(i * j, end=" ")
    print(i * 3)
# 1 2 3
# 2 4 6
for x in [5, 1, 9]:
    if x == 1:
        break
    print(x)   # 5만 출력

반복 안의 반복은 바깥 한 번마다 안쪽이 처음부터 다시 돈다. break는 가장 가까운 반복을 바로 끝낸다.

10반복으로 값 모으기

반복하며 값을 모을 변수는 반복 전에 시작 값을 정해 두고, 반복 안에서 바꿔 간다. 완성된 반복문은 각 장의 힌트에서 확인한다.

  • 합계: 0에서 시작해 원소를 하나 꺼낼 때마다 더한다.
  • 개수: 0에서 시작해 조건에 맞는 원소를 만날 때만 1씩 늘린다.
  • 최댓값: 첫 원소를 지금까지의 최댓값으로 정해 두고, 그보다 큰 원소를 만나면 바꾼다. 반복이 끝나면 가장 큰 값이 남는다.
  • a += 2는 a = a + 2와 같다. 기존 값에 더한 결과를 다시 대입한다.

11시험 코드에서 주의할 것

  • 시험 코드가 str, sum 같은 내장 함수 이름을 변수 이름으로 쓰기도 한다. 내가 쓰는 코드에서는 이런 이름을 피한다.
  • /로 나눈 값은 나누어떨어져도 실수다(8 / 2 → 4.0). %d는 소수부를 버리므로("%d" % (7 / 2) → "3") 나누어떨어질 때만 정수 출력에 쓴다.
  • 출력 설명에 적힌 구분(공백, 줄바꿈)을 그대로 맞춘다. 예제 출력과 한 글자씩 비교해 본다.
