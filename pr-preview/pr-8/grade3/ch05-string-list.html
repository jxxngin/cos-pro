문제 설명

입력 설명

한 개의 문자열 주어집니다.

  • 문자열 길이는 1 이상 100 이하입니다.

유형1 문제 4 · 짝수 위치의 합 · A

  1. 1

    input()은 입력 한 줄을 문자열로 돌려준다. 숫자로 쓰려면 int()로 정수로 바꾼다.

    age = int(input())
  2. 2

    한 줄에 여러 숫자가 오면 split()으로 공백 기준으로 자르고, list(map(int, ...))로 모두 정수로 바꾼다.

    nums = list(map(int, input().split()))   # "1 2 3" → [1, 2, 3]
  3. 3

    원문의 "짝수 위치"는 1부터 센 위치(2, 4, 6번째)다. 인덱스는 0부터 시작하므로 인덱스로는 1, 3, 5다. 리스트[시작:끝:간격]은 시작 인덱스부터 간격만큼 건너뛰며 원소를 꺼낸다. 끝을 비우면 마지막까지 꺼낸다.

    위치1234567
    arr4123270123630
    인덱스0123456
    [10, 20, 30, 40, 50][1::2]    # [20, 40]
  4. 4

    sum(리스트)는 리스트 원소의 합을 돌려준다. 빈 리스트의 합은 0이다.

  1. 3

    range(시작, 끝, 간격)은 시작부터 간격만큼 커지며 끝 바로 앞까지의 수를 만든다. total += x는 total = total + x와 같다.

    for i in range(1, 7, 2):
    print(i)        # 1, 3, 5
  2. 6

    시험 코드는 합을 담는 변수 이름으로 sum을 쓴다. 빈칸에는 total 대신 sum을 쓴다. sum은 내장 함수 이름이라, 이렇게 변수로 덮어쓰면 그 코드 안에서는 sum() 함수를 쓸 수 없다.

유형1 문제 9 · 한 글자씩 늘어나는 부분 문자열 · A

  1. 2

    range(1, len(s) + 1)은 1부터 len(s)까지의 수를 만든다. range의 끝 값은 포함되지 않으므로 1을 더한다.

  2. 3

    문자열[:i]는 앞에서부터 i글자(인덱스 0부터 i - 1까지)를 꺼낸다. print(값, end=" ")은 줄을 바꾸지 않고 끝에 공백을 붙인다.

    sIoT
    인덱스012
    print("IoT"[:2])          # Io
print("a", end=" ")
print("b")                # a b

유형1 문제 9 · 한 글자씩 늘어나는 부분 문자열 · B

  1. 3

    반복문 안에 반복문을 쓸 수 있다. 바깥 i가 한 번 바뀔 때마다 안쪽 j가 처음부터 다시 돈다. range(i + 1)은 0부터 i까지다. end=""을 쓰면 줄을 바꾸지 않고 이어서 출력한다.

    # s = "IoT"일 때
# i = 0 → j = 0       → I
# i = 1 → j = 0, 1    → Io
# i = 2 → j = 0, 1, 2 → IoT
  2. 4

    print(end=" ")는 공백 하나만 출력하고 줄은 바꾸지 않는다. 마지막 부분 문자열 뒤에도 공백이 하나 더 나오는데, 시험 코드도 같다.

  3. 6

    시험 코드는 문자열 변수 이름으로 str을 쓰고, 글자는 "%s" % str[j] 형식으로 출력한다. 빈칸은 안쪽 반복의 범위다.

유형2 문제 7 · 대문자를 소문자로

  1. 2

    문자열.lower()는 대문자를 모두 소문자로 바꾼 새 문자열을 돌려준다. 숫자와 기호는 그대로다. 반대로 upper()는 모두 대문자로 바꾼다.

    print("Hello World!".lower())    # hello world!
