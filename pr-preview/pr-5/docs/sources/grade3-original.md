# 3급 문제 원문 (그대로)

사용자가 준 문제 텍스트를 **그대로** 옮긴 자료다. 학습지의 문제 부분은 이 원문을 고치지 않고 싣는다(→ [rules.md](../rules.md) 1절).

- 복사하면서 딸려 온 `Copy` 글자만 지웠다. 문장, 오타, 줄바꿈, 예제 값은 원문 그대로다.
- 원문에 있는 오류도 그대로 두었다. 알려진 것은 [problems.md](../problems.md) 3절에 적어 두었다.
- 시험 코드 틀(빈칸 문제)은 [grade3.md](grade3.md)에 있다.

---

## 1세트

### 1세트-01

```text
k에 3씩 더하여 크기가 작은 순으로 n개 출력하려 합니다.

두 자연수 k와 n을 전달받아, k에 3씩 더하여 크기가 작은 순서대로 n개 출력해주세요.

입력 설명
두 자연수 k와 n이 주어집니다.

- k는 2 이상 100 이하인 자연수입니다.
- n은 1 이상 100 이하인 자연수입니다.

출력 설명
k에 3씩 더하여 크기가 작은 순서대로 n개 만큼 출력해주세요.

예제

k	n	result
7	5	7 10 13 16 19
3	4	3 6 9 12

입력

7
5

출력

7 10 13 16 19

예제 설명

예제 #1

7에서부터 3씩 더한 5개를 나열하면 7 10 13 16 19입니다.

예제 #2

3에서부터 3씩 더한 4개를 나열하면 3 6 9 12입니다.
```

### 1세트-02

```text
7보다 이전에 있는 숫자의 개수를 출력하려 합니다.

숫자 정보를 가지는 리스트 n을 전달받아, 7보다 이전에 있는 숫자의 개수를 출력해주세요.

입력 설명
숫자 정보를 가지고 있는 리스트 n이 주어집니다.

- 숫자는 1 이상 100 이하인 자연수입니다.
- 숫자 리스트의 크기는 1개 이상 10,000개 이하입니다.
- 7은 한 번 입력되어 있습니다.

출력 설명
7보다 이전에 있는 숫자의 개수를 세어 출력해주세요.

예제

n	result
14 45 50 3 7 11 5 23 9 80	4

입력

14 45 50 3 7 11 5 23 9 80

출력

4

예제 설명

7보다 이전에 있는 숫자는 14, 45, 50, 3입니다. 따라서 4를 출력합니다.
```

### 1세트-04

```text
리스트 arr의 원소 중 짝수 위치에 있는 숫자를 모두 더한 값을 구하려 합니다.

리스트 arr을 전달받아, arr의 원소 중 짝수 위치에 있는 숫자를 모두 더한 값을 출력하도록 코드를 작성하려 합니다. 빈칸(⬜)을 채워 전체 코드를 완성해주세요.

입력 설명
자연수 n과 숫자로 구성된 리스트 arr이 주어집니다.

- n은 1 이상 100,000 이하인 자연수입니다.
- 리스트의 모든 원소는 0 이상 1,000 이하인 정수입니다.

출력 설명
리스트 arr의 원소 중 짝수 위치에 있는 숫자를 모두 더한 값을 출력해주세요.

예제

n	arr	result
7	41 23 27 0 12 36 30	59

입력

7
41 23 27 0 12 36 30

출력

59

예제 설명

23 + 0 + 36 = 59이므로 59를 출력합니다.
```

### 1세트-05

```text
하이픈(-)과 별(*) 모양을 교차하여 출력하려 합니다.

자연수 n을 전달받아, 하이픈(-)모양은 0부터 n-1까지 1씩 커지고 별(*)모양은 n부터 1까지 1씩 작아지면서 모양을 교차하며 출력해주세요.

예를 들어 n이 5일 때, 다음과 같은 기준에 따라 출력합니다.

[기준]
| 하이픈(-) 모양 | 별(*) 모양 |
| 0 | 5 |
| 1 | 4 |
| 2 | 3 |
| 3 | 2 |
| 4 | 1 |

[출력]

*****-****--***---**----*

자연수 n을 전달받아 하이픈(-)과 별(*) 모양을 교차하여 출력해주세요.

입력 설명
자연수 n이 주어집니다.

- n은 2 이상 100 이하인 자연수입니다.

출력 설명
자연수 n에 따라 하이픈(-)과 별(*) 모양을 교차하여 출력해주세요.

예제

n	result
5	*****-****--***---**----*
3	***-**--*

입력

5

출력

*****-****--***---**----*

예제 설명

<예제 #1>
자연수 5를 기준으로 하이픈(-)모양은 0부터 4까지 증가하는 규칙과 별(*)모양은 5부터 1까지 감소하는 규칙을 교차하여 출력하면 *****-****--***---**----*을 출력합니다.

<예제 #2>
자연수 3을 기준으로 하이픈(-)모양은 0부터 2까지 증가하는 규칙과 별(*)모양은 3부터 1까지 감소하는 규칙을 교차하여 출력하면 ***-**--*을 출력합니다.
```

### 2세트-01

### 2세트-05

```text
문제 설명

A와 B는 카드게임을 하고 있습니다.

출력 설명

A가 뽑은 카드의 우선순위가 높으면 A를 출력하고, B가 뽑은 카드의 우선순위가 높으면 B를 출력합니다.

예제 #1. A가 Q를 뽑고, B가 K를 뽑은 상황
K가 Q보다 우선순위가 높으므로 K를 뽑은 B 승리
출력값 : B
예제 #2. A가 K를 뽑고, B가 J를 뽑은 상황
K가 J보다 우선순위가 높으므로 K를 뽑은 A 승리
출력값 : A

입력

QK

출력

B
```
