3장 힌트

2세트-01 · 세 과목 평균 · A

  1. 1

    input()은 입력 한 줄을 문자열로 받는다. split()은 그 문자열을 공백 기준으로 잘라 리스트로 만들고, list(map(int, 리스트))는 리스트의 모든 원소를 정수로 바꾼다. 세 가지를 한 줄로 쓸 수 있다.

    line = input()               # "1 2 3"
parts = line.split()         # ['1', '2', '3']
nums = list(map(int, parts)) # [1, 2, 3]
nums = list(map(int, input().split()))   # 한 줄 버전
  2. 2

    sum(리스트)는 리스트 원소의 합을 돌려준다. 예) sum([1, 2, 3]) → 6

  3. 3

    /로 나눈 결과는 항상 실수다. 예) 9 / 3 → 3.0

  4. 4

    "%.2f" % 값은 값을 소수점 두 번째 자리까지(셋째 자리에서 반올림) 나타낸 문자열을 만든다. round(값, 2)는 끝자리 0을 지우므로 자릿수가 고정되지 않는다.

    print("%.2f" % 3.14159)   # 3.14
print("%.2f" % 88.0)      # 88.00
print(round(88.0, 2))      # 88.0

2세트-01 · 세 과목 평균 · B

  1. 2

    합을 반복해서 더해 갈 변수는 반복문 전에 0으로 시작한다.

  2. 3

    for 변수 in 리스트:는 리스트의 원소를 앞에서부터 하나씩 변수에 꺼내 아래 줄을 반복한다. total = total + x처럼 쓰면 원소가 하나씩 더해진다(누적).

    total = 0
for x in [1, 2, 3]:
    total = total + x
print(total)    # 6
  3. 7

    시험 코드의 빈칸 ①은 입력 처리, ②는 더할 값, ③은 출력 형식이다. 1단계·3단계·5단계에서 쓴 코드와 같다.

  1. 2

    max(리스트)는 리스트에서 가장 큰 원소를 돌려준다. print(a, b)처럼 여러 값을 쉼표로 넘기면 공백으로 구분해 한 줄에 출력한다.

2세트-08 · 두 반의 최장신 · B

  1. 2

    최댓값을 직접 찾을 때는 먼저 첫 번째 원소(리스트[0])를 최댓값이라고 정해 둔다.

  2. 3

    원소를 하나씩 꺼내 지금까지의 최댓값과 비교하고, 더 크면 최댓값을 바꾼다. 반복이 끝나면 가장 큰 값이 남는다.

    nums = [3, 9, 4]
big = nums[0]
for x in nums:
    if x > big:
        big = x
print(big)    # 9

1세트-08 · 사전 순으로 뒤에 오는 문자열 · A

  1. 1

    입력이 문자열이므로 int()로 바꾸지 않는다.

  2. 2

    문자열끼리는 사전 순서로 크기를 비교한다. 사전에서 뒤에 오는 문자열이 더 크다. 그래서 max를 문자열에 쓰면 사전 순으로 뒤에 오는 문자열이 나온다.

    print(max("apple", "banana"))   # banana

1세트-08 · 사전 순으로 뒤에 오는 문자열 · B
