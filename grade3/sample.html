두 수 중 작은 수

1세트-03 함수 작성 조건문min

정수 두 개를 한 줄에 하나씩 입력받아 더 작은 수를 출력한다. (-1,000 ~ 1,000, 서로 다름)

입력출력
27 6427

두 수를 비교해서 작은 쪽을 출력한다.

방법 A 내장 함수 min가장 짧다.
n1 = int(input())
n2 = int(input())
print(min(n1, n2))
방법 B if / else빈칸 문제로 나오면 이 모양이다.
n1 = int(input())
n2 = int(input())
if n1 < n2:
    print(n1)
else:
    print(n2)

헷갈리기 쉬운 점

  • int()를 빼면 문자열끼리 비교한다. "100" < "27"은 True라서 100과 27 중 100을 출력하게 된다.

n번째 원소의 부호

2세트-10 함수 작성 조건문인덱스

정수 5개 리스트 arr(한 줄, 공백 구분)와 n(1~5)을 입력받아, arr의 n번째 원소가 음수면 -1, 0이면 0, 양수면 1을 출력한다.

입력출력
-85 999 111 -32 0 31

n번째 원소는 arr[n - 1]. 그 값을 세 갈래로 나눈다.

풀이 if / elif / else세 갈래는 elif로 나눈다.
arr = list(map(int, input().split()))
n = int(input())
x = arr[n - 1]
if x < 0:
    print(-1)
elif x == 0:
    print(0)
else:
    print(1)

헷갈리기 쉬운 점

  • n번째는 인덱스 n - 1. arr[n]으로 쓰면 3번째(111) 대신 4번째(-32)를 보고 -1을 출력한다.

J · Q · K 카드 게임

2세트-05 빈칸 채우기 문자열 인덱스순서 비교

A와 B가 J, Q, K 중 한 장씩 뽑았다. 우선순위는 J < Q < K. A의 카드와 B의 카드가 순서대로 들어 있는 문자열 cards를 입력받아 이긴 사람(A 또는 B)을 출력한다. 두 카드는 서로 다르다.

입력출력
QKB
KJA

카드를 "JQK" 안의 위치(0, 1, 2)로 바꾸면 크기를 비교할 수 있다. 위치가 뒤인 쪽이 이긴다.

풀이 방법 비교

방법 A index()로 위치를 숫자로 바꿔 비교가장 읽기 쉽다.
cards = input()
priority = "JQK"
if priority.index(cards[0]) < priority.index(cards[1]):
    print("B")
else:
    print("A")
방법 B 반복문으로 위치 찾기 시험 코드 방식빈칸은 아래 틀에서 직접 채운다.
  1. winner를 'A'로 정해 둔다. B가 이기는 경우만 찾으면 된다.
  2. 바깥 for: "JQK"에서 A의 카드(cards의 첫 글자)가 있는 위치 i를 찾는다.
  3. 안쪽 for: i 바로 다음 위치부터 끝까지 보면서 B의 카드가 있으면 B가 더 센 카드이므로 winner = 'B'.

헷갈리기 쉬운 점

  • cards[0]이 A의 카드, cards[1]이 B의 카드다. 문자열도 인덱스는 0부터 센다.
  • 안쪽 반복은 i가 아니라 i + 1부터 시작한다. "A의 카드보다 뒤에 있는 카드"를 찾기 때문이다.
  • "JQK".index("K")는 2다. index()는 처음 나오는 위치를 돌려준다.

2세트-05 · J · Q · K 카드 게임 빈칸 채우기

  2. ②i + 1 — A의 카드 바로 다음 위치부터
